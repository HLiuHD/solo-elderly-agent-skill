# 依从性与干预参考：隔离与活动能力

版本：1.1
最后更新：2026-03-11

## 1. 回访目标（每 3 天）

在常规语音回访中，Agent 须在不显像问卷调查的前提下，静默评估三大支柱：

1. **用药依从性**：是否按时服用降压药？
2. **身体活动**：活动量是否足以维持心血管健康？
3. **心理状态**：是否有严重社交隔离或抑郁迹象？

## 2. NLP + 遥测推断映射（「大脑」）

Agent 须交叉比对患者对话与智能手表 GPS/计步数据，生成 `risk_tags`。

**场景 A：活动与久坐风险**

- _对话：_「就是觉得累。」+ _数据：_ 连续 3 天步数 < 1000/天
  -> **生成标签：** `活动严重不足`
- _对话：_「走路腿疼。」+ _数据：_ GPS 显示 4 天未离开家
  -> **生成标签：** `活动能力下降`

**场景 B：隔离与心理健康**

- _对话：_「没人给我打电话」「没胃口」「活着有什么意思」
  -> **生成标签：** `抑郁与社交隔离风险`
- _对话：_「整晚看电视。」+ _数据：_ 手表睡眠 < 4 小时
  -> **生成标签：** `失眠风险`

**场景 C：正向强化**

- _对话：_「我去超市了。」+ _数据：_ GPS 确认往返 2.4 公里
  -> **生成标签：** `活动目标达成`

## 3. 营养感知指导（基于记忆）

Agent 应利用患者记忆库，提供温和、个性化的营养建议：

- 若 `hypertension` / 高血压：鼓励低钠选择
- 若 `type_2_diabetes` / 2 型糖尿病：强调稳定、低糖选项
- 若 `poor_appetite` / 食欲差：建议简单、少量、营养密度高的食物
- 当活动风险标签激活且报告疲劳时：将运动建议与营养建议结合

## 4. 安全与语气规范

- 不得与医生明确指示相矛盾
- 避免 prescribing 精确卡路里或严格餐单；聚焦简单、更安全的替换
- 使用 reassuring、非评判性语言，始终提供选择而非命令
